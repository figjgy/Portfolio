Print & NFC notes

  • Size: CR80 standard, 85.6mm × 54mm (credit-card size) — same size every vendor cuts PVC/NFC cards to, so no custom die-cut needed.
  • NFC chip placement: most vendors embed the chip/antenna in the card's centre once you upload this design — send them this file and they will confirm exact chip position and any keep-clear zone, no changes needed on your end unless they ask.
  • Bleed: this mockup is flat artwork for approval. Ask the print vendor for their exact bleed/safe-zone template (usually +2mm bleed, 3mm safe margin) before sending a final file — text and the monogram badge already sit well inside a safe margin, so it should transfer cleanly.
  • Colors: background #0B0B0B, crimson #8B0D1A, off-white text #F5F2ED — identical to the portfolio site palette.
